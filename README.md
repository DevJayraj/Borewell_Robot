This is a "BOREWELL RESCUE ROBOT" prototype project which I built as a School Science Fair project and later on went to many inter-school competitions and regional science fairs also.

As the name suggests the project is related to borewell , it was designed to solve a major problem in the society , which was borewell accidents .
More details about the project and it's functioning are provided in the PPT .

This project is based on IoT and uses Arduino-Uno as it's primary brain.
The components are as follow :
-Arduino Uno
-High RPM DC motor
-L298N Motor Driver
-HC-05 Bluetooth module 
-Camera Module
-TowerPro MG996R Heavy Duty Servo Motor 
-Claw/Jaw for holding victim

The claw/jaw functions as a rescue arm , whose movement is controlled with an attached servo motor , which helps to rescue the victim and thus making this prototype fully functioning on a demonstrative level.

The unique part of this prototype is that it included an on-board camera , which gives real-time video-footage of the situation inside the borewell.

The functioning of this prototype is simple :
-The bluetooth module is connected to any portable device(in my case , a smart phone) . 
-Through the custom app built , user can control the vertical movement of the main-board and the opening the closing of the rescue arm.
-User can also access the live footage form the camera through the app.
